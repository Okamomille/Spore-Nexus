# Spore Nexus

A Minecraft resource mod built around mushrooms and their world. Grow resource mushrooms,
let them mutate into new ones, and build machines to harvest and process everything.

> Status: in development. Minecraft **26.2**, **NeoForge** and **Fabric**.

## Features

- **Resource mushrooms**: grow mushrooms on spore soil to harvest fragments, craft them into resources.
- **Mutations**: plant two mushrooms side by side and a new one may appear. A full mutation tree to discover.
- **Machines**: the Spore Nexus altar, the Mycelian Core and more.
- **Modpack friendly**: add your own resource mushrooms with no coding and no resource pack.
- **JEI and Jade support**: recipes, mutations and growth information are shown in game.

## Requirements

| | |
|---|---|
| Minecraft | 26.2 |
| Loader | NeoForge or Fabric (Fabric also needs Fabric API) |
| Required | [Architectury API](https://modrinth.com/mod/architectury-api) |
| Optional | JEI, Jade |

## For modpack authors

You can add resource mushrooms (block, fragments, textures, names, recipes and mutations)
just by editing `config/sporenexus/custom_mushrooms.json`.

See the guide: **[Custom mushrooms (dev wiki)](https://github.com/Okamomille/Spore-Nexus/wiki/Modpack-&-custom-integration)**.
